# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
([tradução em português](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)).

Em resumo: seja respeitoso, acolha pessoas de todas as origens e níveis de experiência,
aceite críticas construtivas e foque no que é melhor para a comunidade. Assédio, ataques
pessoais e linguagem discriminatória não são tolerados.

## Como relatar

Relate comportamentos inaceitáveis abrindo contato privado com as pessoas mantenedoras do
projeto (contato a definir antes da publicação do repositório). Todas as denúncias serão
analisadas com sigilo.
